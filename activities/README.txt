Activities image folder rule

Excel Activities sheet:
  date  = 2026.10.24
  image = 20261024-field-trip.jpg

Place files here:
  images/activities/2026/20261024-field-trip/20261024-field-trip.jpg

Additional photos for the same activity:
  images/activities/2026/20261024-field-trip/20261024-field-trip_01.jpg
  images/activities/2026/20261024-field-trip/20261024-field-trip_02.jpg
  ... up to _20

The year is read from the Excel date. The activity folder name is automatically taken from the image filename without extension.
Therefore, use a unique image filename for each activity.
