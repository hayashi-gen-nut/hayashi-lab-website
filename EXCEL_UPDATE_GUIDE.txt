STEEL STRUCTURE LAB. — Excel / Image Update Guide

1. Normal update
- Edit data/lab_data.xlsx.
- Replace the Excel file on the server.
- Add activity photos under images/activities/.
- Reload the browser (Ctrl+F5 if needed).

2. Activities photos
Example Excel row:
  date  = 2026.10.24
  image = 20261024-field-trip.jpg

Main photo:
  images/activities/2026/20261024-field-trip/20261024-field-trip.jpg

Additional photos:
  images/activities/2026/20261024-field-trip/20261024-field-trip_01.jpg
  images/activities/2026/20261024-field-trip/20261024-field-trip_02.jpg
  ... up to _20

The website automatically reads the year from date and the activity folder from the image filename stem. Use a unique image filename for each activity.

3. Excel sheets
README          : operation notes
News            : news items
Activities      : activity content, image filename, conference information, members, tags
Publications    : peer-reviewed publications
Members         : current members and origin / affiliation
Alumni          : alumni
Collaborators   : domestic / international research collaborators
FacultyProfile  : Gen Hayashi profile
SiteSettings    : access / Google Maps / Google Form / contact settings
Lists           : dropdown masters
Tags            : activity tag master

4. Activities dropdowns
- category_key: choose from dropdown. Labels are generated by the website.
- member_1 ... member_6: choose registered names from Members.
- tag_1 ... tag_6: choose from Tags.
- conference fields are optional and only appear when filled.

5. Important
Do not rename sheet names or header cells.
HTML/JavaScript normally does not need editing for content updates.
